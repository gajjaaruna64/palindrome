# Java Palindrome Checker

A simple Java program that checks whether a given number is a palindrome.

## 📌 What is a Palindrome?

A palindrome is a number that reads the same forward and backward.

### Examples

```text
121  → Palindrome
1221 → Palindrome
1331 → Palindrome

123  → Not a Palindrome
456  → Not a Palindrome
```

## 💻 Program

The program takes a number as input, reverses the number, and compares the reversed number with the original number.

If both numbers are equal, the number is a palindrome.

## ▶️ How to Run

### Step 1: Check Java

```bash
java --version
```

### Step 2: Check Java Compiler

```bash
javac --version
```

### Step 3: Compile

```bash
javac Palindrome.java
```

### Step 4: Run

```bash
java Palindrome
```
